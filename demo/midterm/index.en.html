    How this demo works

    Review ingestion, background processing, validation and persistence use the real project backend. This page reads actual database states and analysis records. The current engine is a Chinese/English rule baseline, not an LLM.

    Failure scenarios inject simulated service errors to demonstrate automatic retries and the attempt limit. Each request includes an extra three-second pause to make state changes visible. The demo uses a separate database.
